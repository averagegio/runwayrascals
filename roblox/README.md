# Roblox place (Rojo)

Luau source for Rascal Runways. Studio setup: [`../docs/ROBLOX.md`](../docs/ROBLOX.md).

```bash
# from this directory
rojo serve
```

Then Rojo plugin → Connect → Play.

Config IDs: `src/ReplicatedStorage/Shared/Config.lua`  
Round timings / scores: `src/ReplicatedStorage/Shared/Balance.json`
